# Exercícios de HTML e CSS

Esta pasta reúne os exercícios práticos realizados durante o estudo de HTML e CSS.

## Estrutura

- `EX001/` — primeiro exercício de página HTML
- `ex002/` — parágrafos, quebras de linha, símbolos e emojis
- `ex003/` — uso de imagens e organização de assets
- `ex004/` — exercícios de semântica e formatação
- `ex006/` — estudo de hierarquia de títulos e elementos
- `ex007/` — formatação de texto e links
- `ex008/` — listas, marcadores e organização visual
- `ex009/` — exercícios de listas e navegação
- `Desafios/` — desafios propostos com foco em aplicação prática

## Objetivo

Organizar os estudos por etapas para facilitar a revisão e acompanhamento do progresso.

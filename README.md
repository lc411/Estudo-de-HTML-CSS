# Estudo de HTML e CSS

Repositório dedicado aos meus estudos e à prática de HTML5 e CSS3. Aqui ficam exercícios, testes e pequenos projetos desenvolvidos durante o aprendizado de desenvolvimento web.

## Conteúdo

Os exercícios estão organizados por pastas:

```text
EXERCICIOS/
├── EX001/  # Primeiro documento HTML
└── ex002/  # Parágrafos, quebras de linha, símbolos e emojis
```

## Como visualizar

1. Clone este repositório:

	```bash
	git clone https://github.com/lc411/Estudo-de-HTML-CSS.git
	```

2. Abra o arquivo `index.html` do exercício desejado em um navegador.

Também é possível abrir a pasta do projeto no VS Code e usar uma extensão como o Live Server para visualizar as páginas durante o desenvolvimento.

## Tecnologias

- HTML5
- CSS3

## Objetivo

Registrar a evolução dos estudos, praticar os fundamentos da web e construir uma base para projetos futuros.

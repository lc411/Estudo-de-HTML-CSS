# Exercícios de HTML e CSS

Esta pasta reúne os exercícios práticos e desafios realizados durante o estudo de HTML5 e CSS3.

## Lista de Exercícios

- **`ex001/`**: Primeiro exercício de página HTML (estrutura básica).
- **`ex002/`**: Parágrafos, quebras de linha (`<p>`, `<br>`), símbolos e emojis.
- **`ex003/`**: Inserção de imagens locais e externas com organização de diretórios.
- **`ex004/`**: Adição de ícones de favoritos (favicon) na aba do navegador.
- **`ex006/`**: Estudo da hierarquia de títulos (`<h1>` até `<h6>`).
- **`ex007/`**: Semântica no HTML e importância das tags estruturais.
- **`ex008/`**: Formatações básicas de texto (negrito, itálico, texto marcado, sobrescrito e subscrito).
- **`ex008b/`**: Outras formatações avançadas (código-fonte com `<pre>` e `<code>`, citações `<q>` e `<blockquote>`, abreviações com `<abbr>`).
- **`ex009b/`**: Trabalho com listas ordenadas (`<ol>`), listas não ordenadas (`<ul>`), listas de definição (`<dl>`) e aninhamento.
- **`ex010/`**: Links externos (`target="_blank"`, `rel="external"`), navegação por links internos entre páginas e links para download de arquivos (PDF e ZIP).
- **`ex011/`**: Mídias em HTML5 — Imagens dinâmicas/responsivas usando `<picture>` / `<source>` e inserção de áudio nativo com a tag `<audio>`.
- **`ex012/`**: Vídeos em HTML5 — Reprodução de vídeos locais (`<video>`) com formatos alternativos e incorporação externa do YouTube via `<iframe>` (com tratamento de restrições de exibição).
- **`ex013/`**: Primeiros passos em CSS — Aplicação de estilos inline diretamente nos elementos HTML.
- **`ex014/`**: Estilos locais e internos — Utilização da tag `<style>` dentro da tag `<head>`.
- **`ex015/`**: Estilos externos — Separação de responsabilidades criando arquivo externo `.css` importado com `<link rel="stylesheet">` e compartilhado entre páginas (`index.html` e `pagina02.html`).
- **`desafio2/` e `Desafios/`**: Desafios práticos integrando páginas, links, imagens e navegação de vídeos.

## Objetivo

Organizar os estudos passo a passo por módulos e conceitos, servindo como consulta rápida e acompanhamento contínuo da evolução prática no desenvolvimento web.
